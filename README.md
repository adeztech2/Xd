## Setup

1. Open the **SESSION** link above, enter your number with country code, and enter the pairing code in WhatsApp under Linked devices.
2. Wait for the bot to message your own WhatsApp chat. Tap **Copy SESSION_ID** or copy the plain text message. The session starts with `ADEZ-XMD~`.
3. Set these variables on your host (or in `.env`):

| Variable | Description |
| --- | --- |
| `SESSION_ID` | The session ID from step 2 (starts with `ADEZ-XMD~`) |
| `OWNER_NUMBER` | Your number, digits only with country code |
| `PREFIX` | Command prefix, default `.` |
| `MODE` | `public` or `private` |

4. Deploy and send `.menu` to check it works.

> Keep your SESSION_ID private. Anyone with it can control your WhatsApp account.
